# Предрегистрация v4 — in/out тайминг по одному BTC (заморожено ДО прогона)

Дата: 2026-10-19. Явная новая причина (не §9-тюнинг провалившегося тренда): v1-тренд был
КРОСС-СЕКЦИОННОЙ корзиной из 30 альтов, и его вердикт задавал impact альтов (издержки доминировали).
Здесь — ОДИН BTC (глубочайший стакан, impact≈0) + МЕДЛЕННЫЙ фильтр (несколько сделок в год).
Это единственное место, где наша сквозная стена (оборот×издержки) структурно НЕ действует.
Вопрос другой: не «обогнать B&H по доходности», а «значимо выше Sharpe при меньшей просадке,
И выше линии BTC+кэш (а не просто разбавление)».

## Данные
BTC дневной SPOT close из `data/mech/spot_klines_1d_binance.parquet` (BTCUSDT, 2017-08-17..2026-10-19,
~9 лет: вкл. медведь-2018, вершину-2021, медведь-2022). Спот = инвестируемо, без funding. rf=0 (кэш=0%).
НЕ трогать data/market (бот BTC). Сверка close с klines_1d_binance (перп) как санити.

## Сигналы (ФИКСИРОВАННЫЙ набор, НЕ перебор окон; n_trials = мощность)
Бинарный in/out (в BTC или в кэш), вычисляется на close дня t, применяется с `shift(1)`, сделка по OPEN t+1:
1. SMA100: close > SMA(100)
2. SMA200: close > SMA(200)
3. tsmom90: доходность за 90 дней > 0
4. tsmom180: доходность за 180 дней > 0
5. tsmom365: доходность за 365 дней > 0
=> n_trials = 5. Зафиксировано. Торгуем ТОЛЬКО на смене сигнала (низкий оборот), не ежедневно.
ФИКСИРОВАНО: long-only (1/0), без плеча, кэш=0%, издержки = BTC taker 4.5bp + impact по costs.py
(на BTC ≈0), вход по следующему OPEN.

## Разбиения
- Выбор лучшего из 5 — ТОЛЬКО на IS (первые 80% времени).
- Форвард-холдаут (последние 20%) — оценка один раз.
- purged k-fold (k=5, embargo 2%) на IS для DSR (n_trials=5).

## Критерий «тайминг улучшает BTC» (ALL)
1. Sharpe(тайминг) > Sharpe(BTC B&H) и РАЗНИЦА ЗНАЧИМА: Jobson–Korkie–Memmel (HAC) И стационарный
   бутстрэп-CI разницы Sharpe исключает 0, с поправкой Bonferroni на n_trials=5 (сырой и скорр. p).
2. ГЛАВНЫЙ null (анти-разбавление): при rf=0 линия BTC+кэш задаётся Sharpe(BTC), поэтому
   «бить линию» ⟺ Sharpe(тайминг) значимо > Sharpe(BTC). Доп. проверка доминирования на плоскостях
   (год.волатильность, maxDD) и (год.волатильность, доходность) против BTC+кэш-смеси равной волы.
   Если Sharpe НЕ выше BTC — меньшая просадка это просто «часть времени в кэше» = разбавление = FAIL.
3. maxDD существенно ниже BTC (≤0.75×), но засчитывается как ЦЕННОСТЬ только при выполненном п.1.
4. Держится на форвард-холдауте (преимущество Sharpe сохраняет знак, согласованно).
5. Не висит на одном сигнале (сколько из 5 бьют BTC) и не на одном режиме: разложить по годам и по
   бычьим/медвежьим фазам; стратегия не должна держаться на избегании ОДНОГО краха (2022).
6. Честность по «пилам»: привести оборот, число сделок, и поведение в боковиках (2019 레인дж, 2022 чоп).

Не выполнен хоть один (кроме holdout-поддержки) → тайминг не улучшает BTC risk-adjusted; фиксируем.

## §9 — чего не делать
- Не перебирать окна SMA/моментума вне набора из 5; не добавлять фильтры/комбо «по результату».
- Не выдавать меньшую просадку за ценность без значимого прироста Sharpe (п.2).
- Не подгонять под избегание одного медведя-2022.
- Не писать код отправки ордеров / не подключаться к реальной торговле.
